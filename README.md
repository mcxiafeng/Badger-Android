## 它能做什么？

**扫码添加** — 扫一扫别人的社交二维码，自动识别平台和账号，一键保存。也可以拍实体名片，AI 帮你提取信息。保存的不只是联系方式，还有这个人的"样子"——头像、昵称、平台身份，都一并记录。

**我的名片** — 把你所有的社交账号汇聚到一张数字名片上，并可以快速切换展示。

**名片夹** — 像真正的名片册一样，把联系人分到不同的名片夹里归类整理。每个名片夹可以有自己的样式，也可以共用同一种，按你的喜好来。支持按需导出。

**NFC 刷写** — 把一个活链写入 NFC 卡片，别人手机碰一下就能打开。重点是：活链的跳转目标可以在 APP 里随时切换，不用重新刷卡。今天指向你的微信，明天换成 GitHub，一张卡搞定。

**去中心化** — 数据存你手机里，AI、云同步、短链接等能力全部对接外部第三方服务，APP 本身不持有你的数据。WebDAV 备份让你自己掌控数据的去向。

## 系统要求

- Android 8.0 及以上
- 相机权限：用于扫描二维码和拍照识别名片
- NFC 权限：用于写入 NFC 标签（可选，不支持 NFC 的设备可正常使用其他功能）
- 网络权限：用于云端同步、AI 识别等功能
