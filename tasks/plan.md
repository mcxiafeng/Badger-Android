# 有界加载与 Android / Go 资源融合

日期：2026-11-22。当前任务已获用户授权实施；前轮闭环任务均已完成。本轮保持本地可独立使用、账号隔离、原同步协议和离线文字资料，不自动提交或发布。

## 方案与不变量

- 联系人由数据库真正分页，FTS 搜索与标签读取也应有界。沿用现有详情、选择、字母索引与返回路径；数据库模型未改不升版本。
- 图片元数据与本机文件可用性分开。同步文字不以下载全部图片为前提；显示时选择缩略图或原图。
- 仅远端可重取文件进入固定预算缓存；本地原件、待上传文件和已有业务图片不做自动删除。切号、旧会话、损坏响应不得写入其他账号。
- Go 扩展图片派生读取，原 URL 原语义不变，保持鉴权和账号隔离。原始 canonical 哈希不受缩略图影响。
- 用合成资料验证分页、搜索、删除/锚点和缓存预算；运行当前构建与相关回归。真机帧耗时、目视和发布环境能力仅按实际结果报告。

## 任务顺序与验收

1. 列表纵切：DAO/Repository 分页 → VM/UI 消费 → 删除、字母跳转和返回锚点。验收：正常及搜索不收集全量联系人；标签只查询已加载范围。验证：聚焦 Room/VM/滚动策略测试、编译。
2. 图片纵切：Go 鉴权缩略图契约 → 客户端持久引用和按需读取 → 固定预算缓存。验收：无图仍能同步文字；原件不被缓存清理；错误图片不入缓存；旧服务行为可保留。验证：Go HTTP/隔离测试，客户端资产/同步测试。
3. 容量与交付：1,000/10,000 合成记录验证有界读取，代表性图片验证容量；Release 包单独构建测量。运行 UI 静态审查和相关门禁，记录已运行、失败或阻塞项目。
